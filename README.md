# SideCodex 📝

A lightweight Chromium Extension that provides either a plain or feature rich notepad, all up to you!


## Features
- Quick notes that are accesible from the toolbar
- Clean and minimal UI, with a light and dark theme
- Ability to choose between using a Rich text or a Plain text editor
- Saving and importing/exporting notes

## Status
Still in occasional development, may add more features in the future
 
## Download

[Install SideCodeX from the Chrome Web Store](https://chromewebstore.google.com/detail/sidecodex/ibchhcdagndogmlklhdnlnomgdcfhale)
